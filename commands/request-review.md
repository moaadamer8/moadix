"Phase $ARGUMENTS is ready for review. Type `REVIEW $ARGUMENTS` for the gate's summary, then `APPROVE $ARGUMENTS <code>` with the current code from your authenticator app."

Do not type, quote, suggest or guess an approval code. Only the operator's own message can record an approval.
