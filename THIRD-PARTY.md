**How the inventory was taken (2026-11-15).** Each image was run with `--network none`. Every `License:` field in its `/usr/share/doc/*/copyright` files (the Debian/Ubuntu machine-readable copyright files) was collected, de-duplicated and sorted. Labels such as `other`, `custom`, `permissive` or a sentence fragment are the packager's names for a licence whose full text is in the same copyright file. `none` marks files with no copyright to license (for example liblzma's generated CRC tables). `probably-PD` marks liblzma's INSTALL and NEWS files. The software the gates actually run (Node.js and npm, CPython, Playwright's bundled Chromium, ZAP, PostgreSQL) has the main licence in the table above.

**Review against the rule.**
- No licence restricts use: no field-of-use, non-commercial or click-through EULA terms were found.
- `no-modification` (autoconf) is the notice on the GPL text itself.
- `Expat-with-advertising-restriction` (openssh-client) is an advertising clause.
- One component has no identified licence: `License: UNKNOWN` for Blackmagic Design's DeckLink API headers in GStreamer's plugins-bad (`gstreamer1.0-plugins-bad`, `libgstreamer-plugins-bad1.0-0`, in the chromium image only). The gates do not run it: they run Node.js and Playwright's own Chromium build, which does not load GStreamer, a library used by the WebKit and Firefox engines. So it does not stop under the rule, but it would if a gate ever ran WebKit or Firefox media playback.
